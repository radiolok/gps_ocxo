# Прошивки DOROGO

| Каталог | Что это | Платформа | Состояние |
| --- | --- | --- | --- |
| [`ilc_demo/`](ilc_demo) | Тестовая прошивка индикатора ИЛЦ1-8/7Л: карта сегментов, часы, секундная стрелка, тесты | Arduino Nano, PlatformIO | Работает; описание — в [`ilc_demo/AGENTS.md`](ilc_demo/AGENTS.md) |
| `dorogo/` | Основное приложение прибора | STM32F407, Zephyr RTOS 4.4 | Не начато |

Архитектура основного приложения — модули, потоки, состояния прибора, интерфейсы управления — описана в [`../hw/ARCHITECTURE.md`](../hw/ARCHITECTURE.md#архитектура-по-zephyr). Драйвер SN755870 и карта сегментов из `ilc_demo` переедут в модуль `ui`.

## Сборка демо индикатора

```sh
cd fw/ilc_demo
pio run -e nanoatmega328 -t upload
```

# Сборочные единицы (assembly units)

Сюда подключаются внешние проекты, из которых собирается DOROGO, — как git submodules. Сейчас каталог пуст.

Кандидаты, если понадобятся:

| Что | Зачем |
| --- | --- |
| Общие библиотеки компонентов DipTrace | Единые посадочные места и УГО для всех плат |
| Плата индикатора ИЛЦ1-8/7Л, если выделится в отдельный проект | Переиспользование в других часах |
| Трассировщик ETM | Отладочная оснастка для стенда |

## Как добавить

```sh
git submodule add https://github.com/<owner>/<repo> au/<name>
git commit -m "au: add <name>"
```

Клонировать репозиторий вместе с сабмодулями:

```sh
git clone --recurse-submodules https://github.com/radiolok/gps_ocxo
# или в уже склонированном:
git submodule update --init --recursive
```

Каждый сабмодуль закрепляется на конкретном коммите; обновление — осознанное: `git -C au/<name> pull`, затем коммит в этом репозитории.

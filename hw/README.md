# Аппаратная часть DOROGO

Целевая архитектура описана в [ARCHITECTURE.md](ARCHITECTURE.md). Здесь — что где лежит.

## Платы

| Каталог | Плата | Состояние | Файлы |
| --- | --- | --- | --- |
| [`mcu_eth_gnss/`](mcu_eth_gnss) | Плата №1: STM32F407VGT6, DP83640 (MII), ZED-F9T, LMK1C1102 | Изготовлена | Нетлист `mcu_eth_gnss.net`; исходники DipTrace (`mcu_eth.dch`/`.dip`) нужно добавить |
| [`display/`](display) | Индикатор ИЛЦ1-8/7Л на двух SN755870 | Изготовлена | `display.dch`, `display.dip` |
| — | Плата №2: OCXO + AD9545 + выходы | Проектируется | — |
| — | Плата питания | Не начата | — |

Схемы и платы — в DipTrace. Для каждой новой платы — свой каталог с исходниками, нетлистом и, по мере появления, Gerber, BOM и PDF схемы.

## Структурные схемы

Картинки в [`img/`](img) сгенерированы скриптом [`img/make_diagrams.py`](img/make_diagrams.py). Чтобы поправить схему, правьте скрипт и перезапустите его:

```sh
python3 hw/img/make_diagrams.py hw/img
```

| Файл | Что показывает |
| --- | --- |
| [`img/system.svg`](img/system.svg) | Системная архитектура: две платы, одна петля частоты |
| [`img/loops.svg`](img/loops.svg) | Кто что корректирует: петля частоты в AD9545, петля времени в STM32 |
| [`img/software.svg`](img/software.svg) | Структура ПО на Zephyr: слои, модули, выводы |
| [`img/stand.svg`](img/stand.svg) | Стенд для отладки платы №1 |

| Каталог | Версия | Состав |
| --- | --- | --- |
